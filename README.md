# Crystal Network（水晶网络）

一个面向 **Minecraft 1.21.1 / NeoForge** 的独立模组，移植并提供 Draconic Evolution 风格的能量水晶网络核心玩法。无需安装 Draconic Evolution；水晶网络相关代码与资源已移入本模组。

模组添加基础、飞龙、神龙三个等级的中继水晶、输入/输出水晶、无线水晶，以及用于建立水晶连接的水晶绑定器。水晶网络支持 FE 能量传输、连接范围与数量限制、输入/输出模式，并包含连接光束和传输粒子效果。具体参数以游戏内实际表现和当前版本实现为准。

## 兼容性与前置

当前项目配置针对以下版本构建：

| 项目 | 版本 |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.72（项目依赖范围为 `[21.1.72, 21.2)`） |
| Brandon's Core | 1.21.1，3.2.1.309 或更高版本（需满足模组依赖要求） |
| CodeChickenLib | 1.21.1，4.6.1.529 或更高版本（需满足模组依赖要求） |

**Brandon's Core 和 CodeChickenLib 是必需前置，需单独安装。** 本模组不会将它们打包进 JAR。虽然运行时无需安装 Draconic Evolution，但本项目部分代码和美术资源源自该模组，详见[第三方来源与许可](THIRD_PARTY_NOTICES.md)。

> 表格列出的是项目当前声明的版本要求，不代表所有更新版本组合都已实际测试。请优先使用与本模组及前置兼容的版本。

## 安装

1. 安装 Minecraft 1.21.1 和 NeoForge 21.1.72。
2. 下载与当前游戏版本匹配的 Crystal Network JAR。
3. 将 Crystal Network、Brandon's Core 和 CodeChickenLib 的 JAR 放入游戏目录下的 `mods` 文件夹。
4. 启动游戏，并确认模组列表中已加载 Crystal Network 及两个前置模组。

客户端和服务器都需要安装本模组及其前置。多人游戏时，请确保客户端与服务器使用兼容的模组版本。

**获取 JAR：** 请查看本仓库的 GitHub Releases

## 游戏内容与基本用法

模组在创造模式物品栏中提供以下内容：

- **基础级、飞龙级、神龙级中继水晶**：用于水晶网络中的中继连接。
- **基础级、飞龙级、神龙级输入/输出水晶**：用于与周围的 FE 能量设备交互。
- **基础级、飞龙级、神龙级无线水晶**：用于无线能量网络交互。
- **水晶绑定器**：选择水晶位置并建立连接。

### 建立水晶连接

1. 手持水晶绑定器，对第一颗可连接的水晶**潜行并右键**，将其位置保存到绑定器。
2. 手持已绑定的绑定器，对另一颗可连接的水晶**右键**，尝试建立连接。
3. 连接受水晶等级对应的范围和连接数量限制；不同维度间不能通过该操作连接。

模组还包含与水晶网络配套的光束和传输粒子效果。各等级的具体容量、速率、范围和连接上限请以当前版本代码或游戏内测试为准；本 README 暂不列未经核实的数值。

## 配方

模组提供十个配方，覆盖三种等级的中继、输入/输出和无线水晶，以及水晶绑定器。配方采用原版材料阶梯：基础级使用铜、铁、红石、石英和紫水晶；飞龙级使用钻石、金锭和末影珍珠；神龙级使用下界合金锭等高阶材料。所有配方产出本模组注册的独立物品。

## 从源码构建

需要 **JDK 21**。在项目目录运行：

Windows：

```powershell
.\gradlew.bat build
```

Linux / macOS：

```bash
chmod +x gradlew
./gradlew build
```

构建成功后，模组 JAR 位于 `build/libs/`。

## 存档兼容提示

此版本使用 `crystalnetwork:` 注册名。若旧测试版本放置过使用 `crystalnetwork:` 自制水晶方块，升级前请备份存档并拆除旧水晶；旧方块实体数据不会自动迁移。
