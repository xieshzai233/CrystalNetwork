# 水晶网络

当前状态：之前的版本已通过 GitHub 云编译并进入游戏测试；当前 1.0.1 修复了测试中发现的绑定器交互、连接粒子、破坏粒子和放置初始化问题。这些修复已做隔离回归检查，仍需重新云编译和游戏内验证。

Minecraft 1.21.1 / NeoForge 独立模组，移植 Draconic Evolution 能量水晶网络的核心逻辑。游戏中不需要安装 Draconic Evolution；模组提供基础、飞龙、神龙三级的中继水晶、输入/输出水晶、无线水晶，以及水晶绑定器。

水晶连接、链接范围与数量、FE 容量与传输、输入/输出模式、无线接收端和空闲接收端休眠沿用 DE 对应实现。客户端使用移植的 DE 水晶 OBJ 模型、贴图、连接光束和传输粒子效果。方块使用正确工具等级并正常掉落自身。

运行前置：

- Minecraft 1.21.1
- NeoForge 21.1.72
- Brandon's Core 3.2.1.309 或更新版本
- CodeChickenLib 1.21.1 4.6.1.529 或更新版本

不需要安装 Draconic Evolution。

下载 GitHub Actions 产物后，先解压 ZIP，将其中的模组 JAR 放进当前游戏实例的 `mods` 目录，并安装上述前置。请移除旧版水晶网络 JAR，避免同时加载多个版本。

本项目的网络核心实现和水晶美术资源来自 Draconic Evolution 1.21.1-3.1.4.633，并移除了对 DE 注册表和全局系统的引用。原项目代码与资源按其各自许可保留来源信息；Brandon's Core 和 CodeChickenLib 作为运行前置单独安装，不会打包进本模组。

## 配方

十个配方沿用已选定的原版材料阶梯：基础级使用铜、铁、红石、石英和紫水晶；飞龙级使用钻石、金锭和末影珍珠；神龙级最高价值材料为下界合金锭。水晶绑定器使用铁、石英和紫水晶。所有配方产出本模组注册的独立物品。

## 使用

- 手持水晶绑定器，潜行右键源水晶，保存绑定。
- 普通右键另一个水晶建立连接，再次右键同一目标可断开连接。
- 源水晶为无线水晶时，右键机器支持 FE 的对应面，建立无线连接。机器的侧面配置需要允许该面的能量输入；无线水晶自身也需要有能量可供输出。
- 潜行右键空气清除绑定；准星指向方块时不会清除绑定。绑定器不会旋转机器。
- 能量端口水晶通过放置时点击的面确定连接方向，支持地面、墙面和天花板。测试旧版时放置朝向不正确的端口水晶，需要拆下重新放置。

## 构建

使用 JDK 21，在项目目录运行：

~~~powershell
.\gradlew.bat build
~~~

产物位于 `build/libs`。

## GitHub 云编译

推送代码后，GitHub Actions 会使用 Java 21 自动构建。也可在仓库的 **Actions → Build JAR → Run workflow** 手动触发。

构建成功后，打开该次运行，在 **Artifacts** 中下载 `CrystalNetwork-JAR`，解压取得模组 JAR。构建失败时，查看 **Build mod** 步骤的日志；失败的运行不会提供 JAR。构建通过仍需在游戏内测试功能。

## 存档

此版本使用 `crystalnetwork:` 新注册名。若旧测试版本放置过 `crystalnetwork:` 自制水晶方块，升级前请备份存档并拆除旧水晶；旧方块实体数据不会自动迁移。
