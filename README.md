# 水晶网络

面向 Minecraft 1.21.1 / NeoForge 的独立水晶能量网络模组。提供基础、飞龙、神龙三级中继水晶、能量端口水晶、无线水晶和水晶绑定器。游戏中不需要安装 Draconic Evolution。

## 下载与安装

从 [Releases](https://github.com/xieshzai233/CrystalNetwork/releases) 下载 `crystalnetwork-1.0.7.jar`，放入当前游戏实例的 `mods` 文件夹。不要把 GitHub Actions 的 ZIP 文件直接放进 `mods`，也不要同时保留多个版本的水晶网络 JAR。

运行依赖：

- Minecraft 1.21.1
- NeoForge 21.1.72 或兼容的 21.1 版本
- Brandon's Core 1.21.1，版本 3.2.1.309 或更新版本
- CodeChickenLib 1.21.1，版本 4.6.1.529 或更新版本

Brandon's Core 与 CodeChickenLib 需要单独安装，本模组不会打包这两个依赖。Draconic Evolution 不需要安装。

## 内容与功能

- 九种能量水晶，分为基础、飞龙和神龙等级。
- 中继水晶之间可连接并传输 Forge Energy；支持等级对应的连接范围、连接数量和传输容量。
- 能量端口水晶可朝向地面、墙面或天花板，并连接相邻机器的 FE 端口。
- 无线水晶可绑定支持 FE 的机器作为接收端，并按原网络逻辑传输能量、休眠和恢复轮询。
- 连接光束、能量传输粒子和无线连接提示沿用水晶网络表现。
- 绑定器可连接或断开水晶，也可为无线水晶添加、移除接收端。
- 潜行时手持其他模组的扳手或配置器右键水晶，可拆除并掉落水晶；水晶绑定器仍用于绑定和连接。
- 将水晶单独放入工作台，可合成清除该水晶携带的方块数据并保留水晶本体，不消耗额外材料。
- 方块具有挖掘掉落，配方仅使用原版材料；神龙级配方中最高价值材料为下界合金锭。

模型和贴图来自 Draconic Evolution 1.21.1-3.1.4.633。相关代码与资源来源及许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 使用方法

1. 手持水晶绑定器，对水晶潜行右键，保存该水晶为连接起点。
2. 普通右键另一颗水晶，建立连接；再次右键同一目标可断开连接。绑定器操作会占用这次交互，不会旋转机器或打开机器界面。
3. 若绑定起点是无线水晶，普通右键支持 FE 的机器对应面可添加接收端。机器该面的能量配置必须允许接收或提取；无线水晶本身也需要有可用能量才能向机器输出。
4. 对无线水晶潜行右键可切换输入/输出模式。潜行右键空气会清除绑定；准星指向方块时不会清除。
5. 能量端口水晶放置时会朝向点击面的反方向，FE 端口位于其朝向的一侧。改变朝向需拆下后重新放置。

水晶的连接范围、方向、能量余量或机器侧面配置不满足要求时，绑定器会提示连接失败原因。将鼠标指向水晶可查看能量和连接状态。

## 配方

所有九种水晶和绑定器均有原版工作台配方。材料阶梯从基础到神龙逐级提高：基础级以铜、铁、红石、石英和紫水晶为主；飞龙级使用钻石、金锭和末影珍珠；神龙级加入下界合金锭作为最高价值材料。具体配方可在 JEI 中查看，也可浏览 `src/main/resources/data/crystalnetwork/recipe/`。

## 构建

需要 JDK 21。在项目目录运行：

```powershell
.\gradlew.bat build
```

JAR 输出到 `build/libs/`。推送代码后，GitHub Actions 也会自动使用 Java 21 构建；成功运行的 `CrystalNetwork-JAR` artifact 是 ZIP 压缩包，下载后解压，取出其中的 `.jar` 文件使用。

## 存档与已知事项

水晶使用 `crystalnetwork:` 注册名。升级旧测试版本前请备份存档；如果旧版本的水晶无法正确显示或工作，请先拆除并重新放置。

1.0.7 修正神龙级中继水晶配方，使其与无线水晶配方区分。1.0.6 支持用其他模组的扳手或配置器潜行右键拆除水晶，并可将水晶单独放入工作台清除其携带的数据。各等级硬度与抗爆值沿用原有设定；粒子效果尚未完成本地游戏内复测。
